# Changelog

All notable changes to dFactory will be documented in this file.

## 0.2.0.dev0

- Rebuild dFactory as a standalone CUDA training framework.
- Add strict configuration and a unified `dfactory` command.
- Add extensible recipe, dataset, and model-provider interfaces.
- Add SFT, AR SFT, MTF, EMTF, AR2BD, and ESTF training recipes.
- Add distributed checkpointing, release qualification, and plugin examples.
- Replace the VeOmni source submodule with an installed runtime dependency.
